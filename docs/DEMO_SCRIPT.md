# 5-minute demo talk track

**0:00–0:45 | Discovery.** “Imagine a 45-person law firm with 8 TB of documents. Before proposing any solution, I'd ask about existing systems, cost drivers, retention, integrations, and downtime tolerance.”

**0:45–2:00 | Live personalization.** Change user count, storage, existing spend, growth, and proposed assumptions. Explain that estimates are hypothetical and not vendor quotes.

**2:00–3:15 | Business case.** Walk through current vs proposed monthly expenses, year-one difference after migration cost, and payback time. Make an unfavorable scenario by increasing license costs; show that the tool doesn't always recommend migrating.

**3:15–4:15 | Architecture tradeoffs.** Explain identity, document application, object storage, audit logging, and phased cutover. Discuss legal hold, security and migration risk.

**4:15–5:00 | Next step.** Export JSON/CSV, request a technical validation workshop, then establish criteria for a pilot. Explain what the prototype *doesn't* do (no customer data or real cloud deployment).
